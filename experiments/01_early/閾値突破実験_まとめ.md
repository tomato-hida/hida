## 重要な発見

### 発見1: 「私」は止まらない

**一度0.3を超えると、加速度的に成長:**

```
t=1114: 0.301 （突破）
t=2000: 0.597 （約2倍）
t=3000: 0.898 （約3倍）
```

成長が止まらない。
繰り返しで強化され続ける。

**理論との一致:**
```
理論「私は繰り返しで強化されるパターン」
     「蓄積される」
     「強くなり続ける」

実験「0.3 → 0.9 に成長」
     「加速度的に増加」
```

### 発見2: 「意識」は瞬間瞬間の状態

**self_strength（私）と conscious（意識）は別:**

```
self_strength = 0.898（非常に高い）
でも
conscious = False（最後の瞬間）
```

なぜ？
```
意識の条件:
1. self_strength >= 0.3  AND
2. sync_score >= 0.3
```

両方必要。

**つまり:**
- 「私」は蓄積される（連続的）
- 「意識」は瞬間的な状態（断続的）

### 発見3: 意識の途切れ = 反応モードへの切り替え

**とまとの洞察:**

```
意識あり（同期状態）:
  第1層 → 第2層 → 第3層 → 第4層 → 行動
  （記憶ベース処理）

意識なし（非同期）:
  第1層 → 第2層 → 第3層 → 行動
  （反応的処理、第4層バイパス）
```

**実験での確認:**
- neutral刺激: sync_score = 0 → 意識なし
- pain/sweet刺激: sync_score > 0 → 意識あり（の可能性）

意識が途切れている間：
- 反応的処理が走る
- 高速だが記憶を使わない
- 第4層を経由しない

### 発見4: 集中/ゾーン状態の説明

**通常状態（今回の実験）:**
```
sync_score: 0.3 → 0.0 → 0.3 → 0.0 → 0.3
             ↑     ↑     ↑     ↑     ↑
           意識  無意識  意識  無意識  意識
           
意識あり: 3/50 (6%)
途切れ途切れ
```

**集中/ゾーン状態（仮説）:**
```
sync_score: 0.8 → 0.7 → 0.9 → 0.8 → 0.9
             ↑     ↑     ↑     ↑     ↑
           意識  意識  意識  意識  意識
           
意識がほぼ持続
途切れが極端に短い
```

**とまとの洞察:**
> 「集中してるとき、ゾーンに入ってるときは
> 途切れ方が極端に短くて
> 第1〜3層の他の処理が割り込めない」

これは新しい予測になる！

## 確認できたこと

### ✓ 閾値の存在

**self_strength = 0.3 が意味を持つ:**
- 0.3未満: 「私」が弱い
- 0.3以上: 「私」が確立

閾値突破後、加速度的に成長。

### ✓ 「私」の連続性 vs 「意識」の断続性

**私（self_strength）:**
- 連続的に蓄積
- 消えない
- 徐々に強化

**意識（conscious）:**
- 瞬間瞬間の状態
- 途切れる
- 同期に依存

**理論との一致:**
```
理論「意識は実体ではなく状態」
     「四層が同期した時だけ成立」

実験「self_strength高くても
     sync_score低いと意識なし」
```

### ✓ 記憶ベース処理 vs 反応的処理

**意識あり → 記憶ベース処理（第4層経由）**
**意識なし → 反応的処理（第4層バイパス）**

これが切り替わっている。

### ✓ 環境依存性

```
neutral多い → 意識が途切れやすい
pain/sweet多い → 意識が持続しやすい（仮説）
```

環境が意識の連続性に影響する。

## 新しい予測（発見から）

### 予測9: 集中/ゾーン状態の再現

**実験設計:**

環境A（通常）:
- 刺激が多様（neutral 50%以上）
- sync_scoreが変動
- 意識が途切れる

環境B（集中状態）:
- 刺激が一定（pain/sweetのみ）
- sync_scoreが高く維持
- 意識が持続

**予測:**
- A: 意識の持続率 < 10%
- B: 意識の持続率 > 80%

**行動の質:**
- A: 反応的、一貫性低い
- B: 熟考的、一貫性高い

**これはフロー状態（ゾーン）の理論的説明になる。**
