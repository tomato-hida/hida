## 予測符号化とは

### 脳の基本原理
脳は常に「次に何が起こるか」を予測している。

```
予測 → 実際の入力 → 誤差計算

誤差が大きい → 驚き、注意、学習
誤差が小さい → 予想通り、安心、継続
```

### 実装した要素

1. **予測モデル** - マルコフ連鎖（簡易版）
2. **誤差計算** - 予測確率と実際の差
3. **注意メカニズム** - 誤差 > 0.5 で注意発動
4. **学習** - 遷移確率の更新
5. **新クオリア** - 予想通り、予想外、馴染み、新しい

## システム構成

### 新しく追加されたクオリア（4個）

| クオリア | 意味 | 発動条件 |
|---------|------|---------|
| expected（予想通り） | 予測が当たった | 誤差 < 0.3 |
| unexpected（予想外） | 予測が外れた | 誤差 > 0.7 |
| familiar（馴染み） | よく知っている | 誤差 < 0.3 |
| novel（新しい） | 初めて、珍しい | 誤差 > 0.7 |

| 感情 | 発動条件 |
|-----|---------|
| surprise（驚き） | 予測誤差が大きい |
| curiosity（好奇心） | 注意が向いた時 |
| relief（安心） | 予測が当たった時 |
| confusion（困惑） | 連続して誤差が大きい |
