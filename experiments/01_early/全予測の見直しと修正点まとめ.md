## 🔧 用語・概念の整理

### 「DNA初期値」の問題

#### 現在の用語の曖昧さ

```python
self.qualia_dna = {'pain': -0.9}
```

**この変数名の問題:**
1. 「DNA」と呼んでいるが実際は何？
2. 遺伝するのか？しないのか？
3. 次世代に引き継がれるのか？
4. **DNA初期値0はありえない**

#### なぜ整理が必要か

**3世代シミュレーションの例:**

**第1世代（親）:**
- 生まれた時: pain_value = -0.9（DNA）
- 学習後: pain_value = -1.0（DNA + 学習）
- 死ぬ時: -1.0

**第2世代（子）の問い:**
- 親の -1.0 を引き継ぐ？（ラマルク説 - 誤り）
- 親の -0.9 からスタート？（ダーウィン説 - 正しい）

**正解:**
- DNA初期値（-0.9）のみ遺伝
- 学習値（-0.1）は遺伝しない
- 子もゼロから学習が必要

#### キリンの首の例

**ラマルク説（誤り）:**
- 親が首を伸ばす努力 → 首が長くなる
- → 子は長い首で生まれる ← 学習値が遺伝？

**ダーウィン説（正しい）:**
- 長い首の遺伝子を持つ個体が生き残る
- → 遺伝子だけが次世代に

#### 明確にすべきこと

**1. 何が遺伝するか:**
- 構造（5層アーキテクチャ）
- パラメータの初期値（-0.9）
- 学習メカニズム（学習率0.01）
- **すべて「ある」（0はない）**

**2. 何が遺伝しないか:**
- 学習した調整値
- 個体の経験
- 記憶の内容

**3. 用語の再定義案:**
```python
# 明確な命名
self.genetic_initial_params = {'pain_sensitivity': -0.9}  # 遺伝する
self.learned_adjustments = {'pain_sensitivity': 0.0}      # 遺伝しない
self.effective_value = -0.9 + 0.0                         # 実際の値
```
