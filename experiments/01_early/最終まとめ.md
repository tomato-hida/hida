### 実験1: 記憶封鎖（予測1の検証）

**設計:**
```
システムA: 正常（記憶あり）
システムB: 第4層無効化（記憶封鎖）

同じ環境（seed=42）
1000ステップ
```

**実装の工夫:**
```python
if self.memory_disabled:
    similarity = 0.0  # 過去との照合をスキップ
    self.activity[3] = 0.0  # 第4層停止
else:
    similarity = self.compare(current)
    if similarity > 0.5:
        self.self_strength += 0.01 * similarity
```

**結果:**
```
システムA（記憶あり）:
  self_strength: 0.268（増加）
  行動: avoid=121, approach=341, neutral=538

システムB（記憶なし）:
  self_strength: 0.000（変化なし）
  行動: avoid=121, approach=341, neutral=538（同じ）
```

**発見:**
1. **記憶の必須性**
   - 記憶なし → 自己なし
   - 記憶あり → 自己形成

2. **行動と意識の分離**
   - 行動は同じ
   - でも自己の形成は違う
   - 行動 ≠ 意識

3. **第4層の本質**
   - 「保存」ではなく「照合」が本質
   - 照合があるから繰り返しを検出
   - 繰り返しが「私」を作る

**理論との一致:**
```
理論「私は繰り返しで強化されるパターン」
     「記憶（第4層）がなければ照合できない」

実験「記憶なし → self_strength = 0」
     「記憶あり → self_strength 増加」

完全一致 ✓
```

### 実験2: 閾値突破の観察

**設計:**
```
正常システム
3000ステップ（通常の3倍）
閾値突破の瞬間を検出
詳細ログ

**結果:**
```
閾値突破: t=1114

★★★ 閾値突破！ t=1114 ★★★
  self_strength: 0.3010
  sync_score: 0.000
  conscious: False（突破の瞬間はneutral刺激）

その後の成長:
t=1114: 0.301
t=1500: 0.434
t=2000: 0.597
t=2500: 0.757
t=3000: 0.898（ほぼ1.0）
```

**グラフ:**

     +------------------------------------
     0      1000     2000      3000
```

**意識の間欠性:**
```
閾値前（50ステップ）:
  意識あり: 0/50 (0%)

閾値後（50ステップ）:
  意識あり: 3/50 (6%)
```

**発見1: 「私」は止まらない**

一度0.3を超えると、加速度的に成長。
```
0.301 → 0.898（約3倍）
```

繰り返しで強化され続ける。

**発見2: 意識の状態性**

```
self_strength = 0.898（非常に高い）
でも
conscious = False（最後の瞬間）
```

なぜ？
```
意識の条件:
1. self_strength >= 0.3  AND
2. sync_score >= 0.3

両方必要
```

**つまり:**
- 「私」は蓄積される（連続的）
- 「意識」は瞬間的な状態（断続的）

**発見3: 意識の途切れ = モード切替**

**とまとの洞察:**
```
意識あり（同期状態）:
  第1層 → 第2層 → 第3層 → 第4層 → 行動
  （記憶ベース処理、熟考）

意識なし（非同期）:
  第1層 → 第2層 → 第3層 → 行動
  （反応的処理、第4層バイパス、高速）
```

**実験での確認:**
```
neutral刺激: sync_score = 0 → 意識なし → 反応モード
pain/sweet刺激: sync_score > 0 → 意識あり → 記憶ベース
```

意識が途切れている間：
- 反応的処理が走る
- 高速だが記憶を使わない
- 第1〜3層の処理が「割り込める」

**これが集中/ゾーン状態の説明に繋がる。**

  self_strength: 1.000（上限到達！）
  意識持続率（全体）: 38.7%
  意識持続率（閾値後）: 70.6%
  閾値突破: t=400（約3倍速い）
  刺激構成: neutral=616（31%）
```

**視覚的比較:**
```

```

**予測との照合:**
```
1. 環境A < 10% → ✗（実測40.0%）

方向性は完全に正しい

```

```
環境A: 0.670

集中環境では「私」が最大まで成長する。

**発見5: 閾値突破速度**

```

環境B: t=400（約3倍速い）
```

集中環境では、はるかに早く「私」が確立される。

**発見6: 意識の持続限界（とまとの洞察）**

**とまとの洞察:**
