## 実験設計

### 比較実験
2つのシステムを同じ環境で実行して比較：

**システムA（正常）:**
- 第1層：身体 → 有効
- 第2層：クオリア → 有効
- 第3層：構造化 → 有効
- 第4層：記憶 → **有効**（正常）

**システムB（記憶封鎖）:**
- 第1層：身体 → 有効
- 第2層：クオリア → 有効
- 第3層：構造化 → 有効
- 第4層：記憶 → **無効**（封鎖）

### 条件統制
- 同じ環境（seed=42で乱数固定）
- 同じ1000ステップ
- 同じ刺激パターン

### 実装方法

```python
class MinimalConsciousness:
    def __init__(self, memory_disabled: bool = False):
        self.memory_disabled = memory_disabled
        # ...
    
    def step(self, sensor_input):
        # 第1〜3層は通常通り処理
        
        # 第4層：記憶
        if self.memory_disabled:
            # **記憶封鎖**
            similarity = 0.0  # 過去との照合をスキップ
            self.activity[3] = 0.0  # 第4層が動いていない
            # self_strengthは増加しない
        else:
            # 正常
            similarity = self.compare(current)
            if similarity > 0.5:
                self.self_strength += 0.01 * similarity
            self.activity[3] = 1.0
```

**重要：**
- 記憶への保存は両方とも行う
- でも封鎖版は「過去との照合」をしない
- つまり第4層の本質的機能（記憶照合）を無効化

## 確認できたこと

### ✓ 記憶の必須性

**記憶がないと「私」は形成されない。**

これは理論の核心：
```
理論「私は繰り返しで強化されるパターン」
     「記憶（第4層）がなければ照合できない」
     「照合できなければ強化されない」

実験「記憶なし → self_strength = 0」
     「記憶あり → self_strength 増加」
```

**完全に一致。**

### ✓ 行動と意識の分離

**行動 ≠ 意識**

- 記憶なしでも行動する
- でも意識（自己）は形成されない

これも理論と一致：
```
理論「反応（第1〜3層）: 行動するが意識なし」
     「意識（第4層経由）: 記憶ベース処理」

実験「システムB: 行動するが自己なし」
```

### ✓ self_strengthの計算メカニズム

**過去との照合が「私」を作る：**

```python
# システムA
similarity = self.compare(current)  # 過去と照合
if similarity > 0.5:
    self.self_strength += 0.01 * similarity  # 増加

# システムB
similarity = 0.0  # 照合しない
# self_strengthは増えない
```

このメカニズムが正しく動作している。

### ✓ 第4層の役割

**第4層の本質：**
- 単なる「保存」ではない
- 「過去との照合」が本質
- 照合があるから「繰り返し」が検出できる
- 繰り返しが検出できるから「私」が強化される

記憶封鎖実験で、これが明確になった。

## コードの説明

### 記憶封鎖の実装

**キーとなる変更点：**

```python
def __init__(self, memory_disabled: bool = False):
    self.memory_disabled = memory_disabled  # フラグ追加
    # ...

def step(self, sensor_input):
    # ...
    
    # 第4層：記憶
    current = (quale_name, value)
    
    if self.memory_disabled:
        # **記憶封鎖モード**
        similarity = 0.0           # 照合しない
        self.activity[3] = 0.0     # 第4層停止
        # self_strengthは増加しない
    else:
        # 正常モード
        similarity = self.compare(current)
        
        if similarity > 0.5:
            self.self_strength += 0.01 * similarity
        
        self.activity[3] = 1.0
    
    # 記憶への保存は両方とも行う
    self.memory.append(current)
```

**重要なポイント：**

1. **保存と照合を分離**
   - 保存: 両方とも行う
   - 照合: 封鎖版はスキップ

2. **activity[3]の意味**
   - 第4層が「動いているか」
   - 封鎖版: 0.0（動いていない）
   - 正常版: 1.0（動いている）

3. **同期への影響**
   - activity[3]=0 → sync_score = 0
   - 第4層が動かないと同期しない
