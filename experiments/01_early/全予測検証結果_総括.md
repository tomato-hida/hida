### 用語・概念の整理

**「DNA初期値」の再定義:**

**現在の問題:**
```python
self.qualia_dna = {'pain': -0.9}
```
- 「DNA」なのか「初期値」なのか曖昧
- 遺伝するのか不明確

**明確にすべきこと:**
1. 何が遺伝するか: 構造、パラメータ初期値、学習メカニズム
2. 何が遺伝しないか: 学習値、経験、記憶
3. DNA初期値0はありえない（必ず何かの値）

**キリンの首の例:**
- ラマルク説（誤り）: 親の努力（学習値）が遺伝
- ダーウィン説（正しい）: 遺伝子（DNA初期値）のみ遺伝

**明確な命名案:**
```python
self.genetic_initial_params = {'pain_sensitivity': -0.9}  # 遺伝
self.learned_adjustments = {'pain_sensitivity': 0.0}      # 非遺伝
self.effective_value = -0.9 + 0.0                         # 実際の値
```
