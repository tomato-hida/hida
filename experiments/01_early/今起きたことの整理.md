
### 4. 第3層：構造化（Structuring）
```python
valueから判断:
- value < -0.5 → avoid (回避)

```

**理論との対応：**
- 「感じを構造的に再編」
- 「世界モデル」（簡易版）
- 「行動決定」

### 5. 第4層：記憶（Memory）
```python
過去のパターンをリストに保存
compare() で類似度計算
similarity > 0.5 なら:
    self_strength += 0.01 * similarity

activity[3] を更新
```

**理論との対応：**
- 「過去の処理パターンの蓄積」
- 「過去との照合」
- 「自己モデルの形成」
- **「繰り返しで強化される私」**

### 6. 第5層：意識（Consciousness）
```python
同期スコア計算:
1. activity_sync = (四層の活動度の幾何平均)
2. direction_match = 方向の一致度
3. memory_engagement = 類似度

sync_score = activity_sync * direction_match * memory_engagement

意識判定:
conscious = (sync_score >= 0.3 and self_strength >= 0.3)
```

**理論との対応：**
- 「四層が同期した状態」
- 「閾値」
- 「意識は状態であり実体ではない」

### 7. 閉じた回路
```python
for t in range(1000):
    sensor = environment.get_input()
    result = system.step(sensor)
    environment.apply(result['action'])
```

**理論との対応：**
- 「環境 → 処理 → 行動 → 環境」の無限ループ
- 「外部からの指示を待たない」
