# HIDA Explorer：内部世界モデルで探索するエージェント

## 概要

前方1マスしか見えないエージェントが、首を回して周囲を見渡し、内部マップを構築しながら探索する。

## 特徴

**飛騨が知らないこと：**
- 世界の大きさ
- 全部で何マスあるか
- 外周が壁かどうか

**飛騨が自分で判断すること：**
- 「行ける未知の場所がなくなった」→ 探索終了
- 内部マップから経路を探索
- 未知の方向を優先して行動

## 構造

```
1. 首を回して4方向見る（N,E,S,W）
2. 見たものを内部マップに記憶
3. 未知の方向を優先して行動選択
4. 「行ける未知がない」で終了
5. 内部マップだけで経路探索（BFS）
```

## 実行

```bash
python main.py
```

## 発見

- カメラ映像と自分の予測を直接比べるのではなく
- カメラ映像から「内部世界」を作り
- 内部世界と予測を比べる

```
❌ カメラ映像 ←→ 自分の予測
✅ カメラ映像 → [内部世界] ←→ 自分の予測
```
