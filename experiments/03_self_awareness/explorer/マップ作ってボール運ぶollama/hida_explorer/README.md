# HIDA Explorer：主観的な世界を持つエージェント

## 概要

前方1マスしか見えないエージェントが、首を回して周囲を見渡し、**主観的な内部マップ**を構築しながら探索・タスク実行する。

## Split-brain構造

```
右脳（行動）: BFS、ルールで決まる（確実）
左脳（作話）: なぜそうしたか後付けで説明

→ ollamaが間違えても行動に影響なし
→ ただ喋るだけ
```

## ollamaを有効にする

`narrator.py` の `USE_OLLAMA = True` に変更

```python
USE_OLLAMA = True  # ここを変更
```

必要なモデル: `gemma3:4b`（または他のモデルに変更可）

## 実行

```bash
python main.py
```

## ポイント

**行動と作話が一致してない：**
```
実際: 未知の方向を選んだ（アルゴリズム）
説明: 「なんとなく左が気になる」（作話）

→ でも自分では「これが理由」だと思ってる
→ 人間も同じかも？
```
