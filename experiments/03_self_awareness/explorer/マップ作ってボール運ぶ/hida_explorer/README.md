# HIDA Explorer：主観的な世界を持つエージェント

## 概要

前方1マスしか見えないエージェントが、首を回して周囲を見渡し、**主観的な内部マップ**を構築しながら探索・タスク実行する。

## 核心

```
普通のロボット: センサー → 行動（反射）
HIDA:          センサー → 主観的な世界 → 行動
                          ↑
                        ここが違う
```

**神視点（客観）** = プログラマーが知ってる世界
**内部マップ（主観）** = HIDAが見たものだけの世界

## 実行

```bash
python main.py
```

## ミッション

1. 探索してマップ構築
2. 赤いボールとゴールを発見 → 位置を記憶
3. ボールの隣に移動 → つかむ
4. ゴールの隣に移動 → 置く

## 飛騨が知らないこと

- 世界の大きさ
- 全部で何マスあるか
- 外周が壁かどうか
- ボールやゴールの初期位置

## 飛騨が自分で判断すること

- 「行ける未知の場所がなくなった」→ 探索終了
- 内部マップから経路を探索
- 記憶した位置に移動

## 意識理論との接続

```
クオリア = 主観的な体験
内部マップ = 主観的な世界

予測誤差 = 「俺の世界」と「実際に見えたもの」のズレ
```

他のロボットは「世界を見てる」
HIDAは「自分の世界を持ってる」
