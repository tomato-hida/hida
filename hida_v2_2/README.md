# HIDA v2.2

このフォルダは HIDA（Human-Inspired Dynamic Architecture）の v2.2 の実装一式です。v2.1（`hida_v2_1/`）のあとの測定を受けて、主導層の決め方を変えました。v2.1 のフォルダと論文は、そのまま残してあります。

設計の説明は `docs/theory/HIDA_architecture_draft.md`、設計の前提は `docs/theory/HIDA_theoretical_premises_draft.md` にあります。

| `CHANGELOG_v2_2.md` | v2.1 → v2.2 の変更と数値 |

## v2.1 から変わったこと

1. **L1（身体）は主導しない。** 身体は信号を渡す側で、主導するのは L2 以降です。指を切ったとき、切れたという信号を出すのが L1、痛みとして前に出るのは L2 です。L1 は追随層としては残ります。
2. **主導層を「いつもの水準からの盛り上がり」で決める。** 各層の活動量を、その層がこれまでに出した最大値で割って揃え、直近の平均を引きます。L2・L3・L4 のうち、この値が 0.30 以上で最大の層が主導層です。v2.1 は「活動量が最大の層」で決めていたため、層ごとの目盛りの違いで主導層が決まっていました。
3. **同期ON/OFFの閾値は 0.30 / 0.19。** v2.1 は 0.08 / 0.05 でした。
4. **初期値のずれを直した。** v2.1 では、低エネルギーで始めた1歩目に L1 の活動量が大きく出ていました。
5. **名前を変えた。** `L5Consciousness` → `SyncState`、`is_conscious` → `sync_on`。第5層は処理層ではなく、L1〜L4 の同期状態を記述する量です。
6. **言語化に使う Claude のモデル名を更新した。** `CLAUDE_MODEL = "claude-sonnet-5-5"`（ファイルの先頭）。API での動作は確かめていません。使うときに確認してください。

結果は、v2.1 の本体に実験用のクラス（`hida_v2_1/hida_l5_relative.py`）を載せた場合と完全に一致します（6シナリオ × 引き込みあり・なし × 30シード、試作版も含めて 720 回の実行で確認）。

## 測定結果（30シード）

シナリオは、A：地図と物の位置を与える、B：どちらも与えない、C：物の位置だけ与える。

| シナリオ | 引き込み | 主導した回数 L2 / L3 / L4 | 交代（1シード平均） | 同期ONの頻度 | ゴール到達 |
|---|---|---|---|---|---|
| A | なし | 89 / 0 / 191 | 3.73 | 12% | 30 |
| A | あり | 90 / 0 / 175 | 4.00 | 13% | 30 |
| B | なし | 52 / 23 / 319 | 2.77 | 8% | 20 |
| B | あり | 51 / 35 / 302 | 3.53 | 15% | 19 |
| C | なし | 56 / 105 / 148 | 4.30 | 30% | 30 |
| C | あり | 70 / 61 / 148 | 5.27 | 34% | 30 |

- 地図を与えないシナリオで、三層とも主導します。A で L3 が 0回なのは、予測誤差が出ないためです。
- 引き込みありで、主導層の交代が増えます（B：符号検定 両側 p = 0.002、C：p = 0.001、A：p = 0.125）。
- 主導強度と次のステップの追随層の活動の相関は、A と B では引き込みありのときだけ、時刻を入れ替えた対照より高くなります（A：+0.194、p は 0.001 未満。B：+0.161、p = 0.001）。C では引き込みなしでも高くなります。
- `test_entrainment_ablation.py`（シナリオ A）では、主導イベント直後の追随層の活動上昇が、30シードすべてで引き込みありの方が大きくなります（0.0970 と 0.0635）。v2.1 では 30シード中25でした。ただし、この量は揃えたあとの値で、v2.1 の値とは大きさを比べられません。

## 確かめていないこと

- 仮に置いた値（`PEAK_INIT`、`PEAK_DECAY`、`BASE_ALPHA`、`PROMINENCE_THRESHOLD`、ON/OFF の閾値）を変えたときに、結果がどう変わるか。
- L2 と L4 が主導したステップの中身が、状況に合っているか（L3 は確かめた。`CHANGELOG_v2_2.md`）。
- 引き込みが行動を良くするか。行動が変わるシードはありますが、ゴール到達は増えていません。エネルギー 0.3 で始めた B では、引き込みありで到達が減ります（8 → 5）。
- 同期ONの判定は、言語化を行うかどうかにしか使われていません。試作 `SyncStateOn` は、同期ONのあいだ全体として同期しやすくするものですが、今の環境では事象が1〜数ステップで終わるため効果が小さく、扱いを決めていません。
- 環境は一つ（10×10 のグリッド）です。
