# HIDA v2.2 実装改訂記録

**対象：** `hida_v2_2/hida_unified_v2_2.py`（もとは `hida_v2_1/hida_unified_v2.py`）
**改訂日：** 2026年11月25日
**改訂者：** とまと（測定とコード：Claude Fable 5.2）
**位置づけ：** v2.1 のあとの測定で、v2.1 の主導層の決め方では層ごとの目盛りの違いで主導層が決まっていることが分かった。その結果を受けて、主導層の決め方を変えた。あわせて、L1 を主導層の候補から外すという設計の変更を入れた。測定の経過と数値は `hida_v2_1/CHANGELOG_v2_2_work.md` にある。v2.1 の本体と論文は変更していない。

## 変更1：L1 を主導層の候補から外した

身体は信号を渡す側で、主導するのは L2 以降である。指を切ったとき、切れたという信号を出すのが L1、痛みとして前に出るのは L2。ホルモンなど身体内部の状態も同じで、L1 は「今、体はこういう状態だ」と伝え、それを受けた L2 が主導する。

- `LEADER_CANDIDATES = ('L2', 'L3', 'L4')`
- L1 は追随層としては残る（引き込みゲインを受け、追随整合性にも数える）。
- `sync_type` が取る値は `'L2'`、`'L3'`、`'L4'`、`None`。

## 変更2：主導層を「盛り上がり」で決める

### 問題

v2.1 は「活動量が 0.3 以上で最大の層」を主導層としていた。活動量は層ごとに別の定数で割っている（L1 は 1.0、L2〜L4 は 3.0）。測定すると、L1 の活動量はどのシナリオでも 0.2 前後までしか上がらず、地図を与えないシナリオでは L4 が上限の 1.00 に張り付いて、L4 だけが主導した（地図なし・物なしで L4 552回、他は 0回）。

### 修正

```
揃えた活動量 = 活動量 ÷ その層がこれまでに出した最大値
盛り上がり   = 揃えた活動量 − その層の直近の平均
主導層       = L2・L3・L4 のうち、盛り上がりが 0.30 以上で最大の層
主導強度     = その盛り上がり
```

- 最大値は1ステップごとに 0.995 倍に下がる（`PEAK_DECAY`）。最初の値は `PEAK_INIT`。
- 直近の平均は、係数 0.2 の指数移動平均（`BASE_ALPHA`）。
- `LEADER_THRESHOLD` は `PROMINENCE_THRESHOLD` に置き換わった。
- 追随整合性、同期スコア、平滑化、引き込み機構の計算は v2.1 のまま。入力が揃えた活動量になっただけである。

## 変更3：同期ON/OFFの閾値

0.08 / 0.05 → **0.30 / 0.19**。揃えた活動量は値が大きく、もとの閾値ではシナリオ A の同期ONが 9割を超える。v2.1 のときと同じ基準（シナリオ A、引き込みありで、同期ONの頻度を前の版と同程度＝15% に保つ）で決めた。OFF は v2.1 と同じ比率（ON の 0.625 倍）。

## 変更4：初期値のずれ

v2.1 では、同期判定が持つ「前ステップのエネルギー」が 1.0 で始まる。エネルギー 0.3 で始めると、1歩目の L1 の活動量が 0.71 になっていた。最初の測定のときに、開始時点の実際の値を入れるようにした。

## 変更5：名前

| v2.1 | v2.2 |

## 変更6：Claude のモデル名

`"claude-sonnet-4-20250514"` → `CLAUDE_MODEL = "claude-sonnet-5-5"`（ファイル先頭の定数）。API での動作は確かめていない。

## 追加：SyncStateOn（試作・未検証）

同期ONのあいだだけ、引き込みを2倍にし、主導になる敷居を 0.30 から 0.20 に下げる。「一度ONになると、事象が続いているあいだは全体として同期しやすい。主導層は入れ替わってよい」という考えの試作である。`HIDA` は既定では使わない。

今の環境では、同期ONの区間が少しつながる程度の効果だった（地図なし・物ありで、区間の平均が 4.8 → 6.1 ステップ、最長 7 → 10）。ゴール到達は変わらない。長く続く事象がある環境で確かめてから扱いを決める。

## 確認

- **v2.1＋実験実装との一致：** v2.1 の本体に `hida_v2_1/hida_l5_relative.py` のクラスを載せた場合と、主導層・主導強度・同期スコア・各層の活動量・同期ON・行動・位置・エネルギーが、全ステップで一致した。6シナリオ × 引き込みあり・なし × 30シードで、既定のクラスと試作のクラスそれぞれ 360 回、計 720 回の実行。
- **引き込みあり・なしの比較（`test_entrainment_ablation.py`、シナリオ A）：**

| 測定量 | OFF (K=0) | ON (K=0.5) |
|---|---|---|
| 主導イベント直後の追随層活動上昇（平均） | 0.0635 | 0.0970 |
| 時間遅れ相関 r(主導強度 t, 追随平均 t+1) | +0.150 | +0.255 |
| シード単位の比較（ON > OFF） | — | 30 / 30 |

  値は揃えたあとの活動量で計算している。v2.1 の値（0.0154／0.0174、−0.110／−0.031、25/30）とは大きさを比べられない。

- **シナリオごとの結果とシャッフル対照：** `README.md` と `hida_v2_1/CHANGELOG_v2_2_work.md` の表と同じ値が、このフォルダのスクリプトで出る。
