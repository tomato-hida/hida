## 測定1：シャッフル対照

### 問い

§4.3.12 の時間遅れ相関 r(主導強度 t, 追随平均 t+1) は両条件で負だった。活動量を変化量で定義しているせいで最初から負に寄っているのか。

### 方法

同じシードの中で、主導イベントに対応させる「次のステップ」を、別の主導イベントの次のステップと入れ替える。時刻の対応だけが壊れ、主導層の種類・主導強度・活動量の分布は残る。2000回くり返した平均を基準点とする。

### 結果

| | 実測 r | 基準点 | 実測 − 基準点 | p |
|---|---|---|---|---|
| OFF (K=0) | −0.110 | +0.136 | −0.246 | 0.001 |
| ON (K=0.5) | −0.031 | +0.170 | −0.201 | 0.008 |

- 基準点は正だった。負に寄る偏りはなかった。
- 負の相関は時間の並びに実際にある関係である。引き込みなしでも出る。
- 追随層の活動上昇（0.0154／0.0174）は、基準点（0.0185／0.0187）と区別がつかなかった（p = 0.09／0.41）。

実行：`python3 measure_v22.py`

## 測定3：シナリオを変える

地図と物の位置を与えるかどうかを変えた（A：両方与える、B：どちらも与えない、C：物の位置だけ与える）。v2.1 の決め方、引き込みなしの結果：

| シナリオ | 活動量の最大値 L1 / L2 / L3 / L4 | 主導した回数 L1 / L2 / L3 / L4 | 交代（1シード平均） |

| A | 0.18 / 0.50 / 0.00 / 0.37 | 0 / 66 / 0 / 90 | 1.00 |

- L1 の活動量は主導の閾値 0.30 に届かない。

## 変更1：L1 を主導層の候補から外す（設計の変更）

### 理由

身体は信号を渡す側で、主導するのは L2 以降である。指を切ったとき、切れたという信号を出すのが L1、痛みとして前に出るのは L2。ホルモンなど身体内部の状態も同じで、L1 は「今、体はこういう状態だ」と伝え、それを受けた L2 が主導する。実際の人間で L1 そのものが主導する例は思い当たらない。

### 影響

- L1 は追随層としては残る（引き込みゲインを受け、追随整合性にも数える）。
- v2.1 論文には「L1主導」が18か所ある（§2.3 の L1 の役割2、§5.2、状態の表、指を切る例の段階1、ボディスキャン瞑想、動物の表など）。論文は変更していない。次の版で直す。
- 草稿二つ（アーキテクチャ 0.2、理論的前提 0.3）とルートの README は直した。

### 決めたこと

- 指を切る例の段階6「絆創膏を探す」は、L4 と L3 の交代とする。探すという行為は、記憶と確認の繰り返しだからである。体は追随して動く。

### 決めていないこと

- v2.1 で「L1主導」としていた状態（パニック様状態、身体化、解離様状態、身体意識）を、どの主導層で書くか。
- 眠気、発熱、麻酔のように、身体の状態が全部の層の感度を一度に上下させる経路。`hida_v21_work.py` に試作（RAS の大域ゲイン）があるが、検証していない。

## 変更2：主導層を「盛り上がり」で決める（実験実装）

`hida_l5_relative.py`。本体の `L5Consciousness` を継承し、活動量の測定と主導層の特定だけを置き換える。

1. 各層の活動量を、その層がこれまでに出した最大値で割って 0〜1 に揃える（最大値は1ステップごとに 0.995 倍。最初の値は `PEAK_INIT`）。
2. 揃えた値から、その層の直近の平均（係数 0.2 の指数移動平均）を引く。これが盛り上がり。
3. L2・L3・L4 のうち、盛り上がりが 0.30 以上で最大の層が主導層。

あわせて、「前ステップのエネルギー」を開始時点の実際の値で始めるようにした。

### 結果

| シナリオ | 引き込み | 主導した回数 L2 / L3 / L4 | 交代（1シード平均） | 同期ONの頻度 | ゴール到達 |
|---|---|---|---|---|---|
| A | なし | 89 / 0 / 191 | 3.73 | 12% | 30 |
| A | あり | 90 / 0 / 175 | 4.00 | 13% | 30 |
| B | なし | 52 / 23 / 319 | 2.77 | 8% | 20 |
| B | あり | 51 / 35 / 302 | 3.53 | 15% | 19 |
| C | なし | 56 / 105 / 148 | 4.30 | 30% | 30 |
| C | あり | 70 / 61 / 148 | 5.27 | 34% | 30 |

- 地図を与えないシナリオで、三層とも主導した。
- B で L3 が主導した23ステップ（引き込みなし）は、危険ゾーンの発見 21、ゴールの発見 1、新しい物の発見 1。
- 交代回数は引き込みありで増えた（B：ON が多い 13、少ない 1、同じ 16、p = 0.002。C：15、1、14、p = 0.001。A：4、0、26、p = 0.125）。
- 行動と位置の並びが変わったシードは、A と C で 0、B で 9。
- エネルギー 0.3 で始めた B では、ゴール到達が引き込みなしで 8、ありで 5。引き込みは L1 のゲインも上げるので、消費が増える。

### シャッフル対照（この決め方で）

| シナリオ | 引き込み | 実測 r | 基準点 | 実測 − 基準点 | p |
|---|---|---|---|---|---|
| A | なし | +0.150 | +0.078 | +0.072 | 0.155 |
| A | あり | +0.255 | +0.060 | +0.194 | 0.001 未満 |
| B | なし | +0.235 | +0.168 | +0.067 | 0.206 |
| B | あり | +0.287 | +0.126 | +0.161 | 0.001 |
| C | なし | +0.368 | −0.076 | +0.444 | 0.001 未満 |
| C | あり | +0.435 | +0.050 | +0.385 | 0.001 未満 |

A と B では、引き込みありのときだけ相関が基準点より高い。v2.1 で確認できなかった正の向きが出た。C では引き込みなしでも高い。

実行：`python3 scenario_probe.py relative`、`python3 measure_v22.py relative A`（B、C も同じ）

## 変更3：同期ON/OFFの閾値（実験実装）

揃えた活動量は値が大きく、0.08/0.05 のままだとシナリオ A で同期ONが 9割を超える。v2.1 のときと同じ基準（シナリオ A、引き込みありで、同期ON頻度を前の版と同程度＝15% に保つ）で決め直し、**ON 0.30、OFF 0.19** とした。OFF は v2.1 と同じ比率（ON の 0.625 倍）。

エネルギー 0.3 で始めた場合の同期ONの頻度は、引き込みなし／ありで、A：0%／33%、B：13%／26%、C：31%／54%。六つの条件すべてで、引き込みありの方が高い。
